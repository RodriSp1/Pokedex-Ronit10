# PokeRonit

Pokédex web temática inspirada en los Pokémon de tipo Fuego, conectada en tiempo real a la **PokéAPI** para consultar información, descripciones en español y cadenas evolutivas completas.

## Funcionalidades
- Búsqueda de Pokémon por nombre o número de Pokédex.
- Sección de acceso rápido a favoritos de tipo Fuego con las líneas evolutivas de **Chimchar** y **Torchic**.
- Visualización de sprite oficial, número de registro y descripción en español.
- Renderizado dinámico de toda la cadena evolutiva, incluyendo ramificaciones y Megaevoluciones.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (Fetch API / Async-Await)
- [PokéAPI](https://pokeapi.co/)

## Ejecución local
1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en cualquier navegador con acceso a internet.
